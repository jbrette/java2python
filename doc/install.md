## Installation

java2python requires Python 3.14 or newer and is managed with [uv][].

### As a Tool

Install the `j2py` command from a checkout or from github:

    $ uv tool install .
    $ uv tool install git+https://github.com/natural/java2python

Or run it once without installing:

    $ uvx --from git+https://github.com/natural/java2python j2py SomeFile.java

### Development Version

Clone or fork the repo, then create the project environment:

    $ uv sync
    $ uv run j2py SomeFile.java


### Dependencies

java2python has no runtime dependencies.  The parser is generated by [ANTLR][]
3.1.3, and the matching Python runtime is vendored in `java2python/lang/antlr3`
(ported to Python 3; BSD license in that directory).

The development dependencies (what you need if you're coding java2python) are
[uv][], GNU make, and a JDK for the test suite.  Regenerating the parser from
`Java.g` also needs the [ANTLR][] 3.1.3 tool.


[ANTLR]: http://www.antlr3.org
[uv]: https://docs.astral.sh/uv/
